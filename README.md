# Avalon GV - releases

APKs do app Avalon GV (guarda-volumes para eventos) e o arquivo `latest.json`
que os celulares consultam para saber se existe versão nova.

Instalação em um celular novo: baixe o `.apk` da release mais recente em
**Releases**, abra o arquivo e confirme a instalação. Depois disso o próprio
app avisa quando sair atualização.

O código-fonte fica em um repositório privado.
